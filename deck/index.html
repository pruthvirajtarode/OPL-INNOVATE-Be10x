The Formula

Prompting Framework

TASK + CONTEXT + SOURCE + CONSTRAINT + OUTPUT

TASK: What do you want Copilot to do?
CONTEXT: Who is the audience? What is the goal?
SOURCE: Which files/data should it use?
CONSTRAINT: What limits? (e.g., "Use only provided info")
OUTPUT: Format, length, tone.

Prompt Rescue

Fix this prompt:

"Summarize this."

Better:

"You are a product manager. Draft a concise 5-bullet update to the engineering team summarizing the attached project brief. Tone should be clear and accountable."
Data & Security

ACCESS ≠ MAGIC

Copilot does not magically give you access to everything.

It uses your existing permissions.
Always use approved company accounts and verify important outputs.

From Messy to Structured

Turn rough project notes into a professional project brief.

"Rewrite these notes into a project brief. Include sections for Problem, Goal, Scope, Timeline, and Risks."

Level Up

"Rewrite this for a senior stakeholder."

X

Excel

Analyze and Insight

Ask natural-language questions about your data table.

  • Which product has the highest volume?
  • What is the average resolution time?
  • Create one useful chart.

Level Up

"What evidence in the data supports each recommendation?"

This teaches analytical grounding. No invented conclusions.

P

PowerPoint

Document to Presentation

Transform a 1-page project brief into a 6-slide executive presentation.

"Create a presentation from [file]. Provide speaker notes for each slide."

Structure

  1. Problem
  2. Current situation
  3. Insight
  4. Proposed solution
  5. Impact
  6. Next steps
T

Teams

Meeting Recap

Extract decisions, action items, and follow-ups from transcripts.

"What did we decide? List action items with owner and due date. Draft the follow-up message."

Spot the Problem

If the transcript doesn't specify an owner or due date, but Copilot lists one anyway.

Lesson: Copilot hallucinated. Always use [confirm owner] placeholders.
